📚 Step-by-Step Tutorial

How to Set Up & Run CloudBox with Firebase

1

Create a Free Firebase Project

Navigate to console.firebase.google.com and sign in with your Google account.

  • Click "Add project" (or "Create a project").
  • Enter a project name (e.g. my-cloud-storage).
  • Disable Google Analytics (optional for simplicity) and click "Create Project".
2

Enable Firebase Storage

In the left sidebar of your Firebase Console:

  • Click on "Build" > "Storage".
  • Click "Get started".
  • Choose "Start in test mode" (or default rules) and click Next.
  • Select your Cloud Storage location (e.g. us-central1 or nearest) and click "Done".
3

Configure Storage Security Rules

To allow file uploads and downloads during development and learning, update your rules:

Firebase Storage Rules 
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if true;
    }
  }
}

Click "Publish" in the Firebase Rules tab to apply these changes.

4

Get Your Web App Config

  • In Firebase Console, click the ⚙️ Project settings gear in the left sidebar.
  • Scroll down to the "Your apps" section.
  • Click the Web icon </> to register an app (name it e.g. CloudBox Web).
  • Copy the generated firebaseConfig values into js/firebase-config.js or paste them via the "Firebase Setup" button in this app!
5

Run the Project Locally

Because ES Modules are used, run this project through any lightweight local HTTP server:

Option A: VS Code Live Server 
Right-click index.html -> "Open with Live Server"
Option B: Python (Terminal) 
python -m http.server 3000
Option C: Node.js npx (Terminal) 
npx serve .
